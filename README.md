# QR-Code-Generator

A simple Android app to generate QR Codes from text or URLs.

## 📱 Features
- Convert any text or URL into QR Code
- Clean and easy to use interface
- Built with Kotlin

## 🚀 How to Run
1. Clone this repository
2. Open it in Android Studio
3. Build and Run on your device or emulator

## 🛠 Tech Stack
- Language: Kotlin
- IDE: Android Studio
- Min SDK: 21
